rox-filer-classic-mimetype-icon-theme
=====================================

Homepage: <https://github.com/step-/rox-filer-classic-mimetype-icon-theme>

This repository contains the MIME-type icons used by the ROX-Filer file
manager, extracted from the [jun7 fork] of the original ROX-Filer
repository at commit `c5de8d8` (July 18, 2023).

[jun7 fork]: https://github.com/jun7/rox-filer
